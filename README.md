# Khansa Ehsan — Portfolio

My personal portfolio website, presenting selected full-stack projects, technical skills, education, and ways to get in touch.

## Highlights

- Project archive with live links, repositories, and technical context
- Light and dark themes
- Responsive skills constellation and capability index
- Development journey, credentials, FAQ, and contact section
- Accessible external links and a downloadable resume

## Built with

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available commands

```bash
npm run dev    # Start the development server
npm run lint   # Run ESLint
npm run build  # Create a production build
npm start      # Run the production build
```
